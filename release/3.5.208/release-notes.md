X-Tools 3.5.208

- Базовый размер главного окна — 1493×1047, как на образце. После обновления размер применяется один раз для всех пользователей и ограничивается разрешением экрана. Дальнейшее ручное изменение размера и положения сохраняется.

- Сохранено исправление ответов на вопросы о семье с указанием ID из версии 3.5.207.

Обновление из игры: /update. Для ручной установки доступны X-TOOL.lua и полный X-Tools.zip.

Проверено: LuaJIT, миграция настроек, размеры на разных разрешениях, окраска всех тем и геометрия баннера, регрессии семейных запросов, контрольные суммы ресурсов и полного архива. Внутри GTA/SA-MP обновление не запускалось.
