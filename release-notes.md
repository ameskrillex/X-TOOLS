X-Tools 3.5.206 / переходный загрузчик 3.5.205

Исправлен переходный загрузчик: установка выполняется из главного потока MoonLoader; SHA-256 не вызывает wait. Убрана комбинация вложенного потока и ожидания при хешировании, присутствовавшая в упавшей версии 3.5.203.

Для 3.5.171: /update устанавливает совместимую 3.5.205, затем автоматически полную 3.5.206. Все изменения 3.5.204 сохранены.

Если уже установлена и падает 3.5.203, завершившийся скрипт не способен получить исправление с сервера. Закройте игру и один раз восстановите X-TOOL.lua из X-TOOL.lua.pre-bridge.bak (или X-TOOL.lua.bak). После запуска повторите /update. Настройки и журналы восстанавливать не требуется.

Проверки: реальные транзакции 3.5.171 → 3.5.205 → 3.5.206, основной цикл переходного загрузчика без дочерних потоков, сетевые ограничения, целостность и сохранение настроек.
