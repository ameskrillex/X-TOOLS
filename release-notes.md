X-Tools 3.5.211 — запуск обновления через /update

- Обработчик /update ставит запрос в очередь; запуск выполняется на следующем игровом кадре после возврата из обработчика чата. Повторные команды в одном кадре объединяются.
- Если новая версия уже найдена, команда использует тот же путь установки, что и кнопка в /xt, без повторного скачивания манифеста.
- Проверка SHA-256 уступает время игровому циклу, в том числе при проверке большого пакета ресурсов.
- В moonloader.log записываются этапы обновления для диагностики возможных нативных вылетов.

Если /update вылетает на прежней версии, установите этот выпуск через /xt → Настройки → Система либо замените X-TOOL.lua при закрытой игре. После обновления полностью перезапустите игру.

Проверено: 39 тестов LuaJIT, целостность скрипта и 367 ресурсов, полный архив. Нативный вылет в GTA не воспроизведён; устранены найденные различия запуска команды и кнопки.
