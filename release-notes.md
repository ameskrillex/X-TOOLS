X-Tools 3.5.296 — обновление без ручных архивов

Введите /update в игре. Скрипт и все ресурсы актуальной версии скачиваются с GitHub автоматически с проверкой размеров и SHA-256. Настройки и журналы сохраняются.

Старые версии автоматически проходят совместимый промежуточный загрузчик 3.5.295, затем устанавливают 3.5.296. Вручную скачивать архив не требуется. При сетевом сбое повторите /update. Будущие версии получают обновления напрямую из нового канала.

Кастомный ESC полностью удалён. После обновления полностью перезапустите GTA, чтобы выгрузить старое меню и нативные компоненты.

Для первой установки достаточно поместить X-TOOL.lua в moonloader: скрипт сам загрузит недостающие ресурсы. MoonLoader и SAMPFUNCS должны быть установлены.

38 автоматических проверок прошли, включая реальные загрузчики старых релизов, полный переход, повтор после сетевого сбоя, сохранность настроек, откат и готовую сборку. Проверка на стенде не заменяет проверку живой игры.
