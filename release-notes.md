X-Tools 3.5.327 — проверки аккаунтов и статусы администраторов

- Добавлена /pesok ID: проверка последнего IP через /get и /lip с отчётом «Проверка на Sandbox» в /a. В отчёт включаются только аккаунты из /lip, которые сейчас онлайн, с их ID и без повторов. Окна проверки не открываются.
- Повторный вызов команды проверки, в том числе без аргументов, отменяет текущие запросы и оставшиеся строки отчёта. Поддерживаются /areg, /pesok, /cget, /reg, /offreg, /cas, /cip, /clip и /namestore.
- Исправлено зависание повторных /areg и /pesok для того же игрока или IP.
- Добавлен отключаемый отчёт в /a после ручного /unban: дата бана и оставшийся срок из /baninfo. Отправляется только после подтверждения разблокировки. По умолчанию выключен; настройка находится в основных инструментах.
- В чекере появился отключаемый опрос /admins каждые 15 секунд. Автоматические ответы скрываются локально, ручной запрос остаётся видимым. Отправка не закрывает чат и не меняет набранный текст.
- Статусы администратора отображаются как [AFK], [INV] и sp -> Nick [ID], с отдельными цветами. Метка ONLINE убрана. Устаревшие статусы очищаются.
- Улучшена подсветка онлайн-аккаунтов с ID в результатах проверки и защита от повторного использования ID.
- Исправлена сводка /areg при сбое геосервиса: технические ошибки не отправляются в /a и не считаются различием геопозиций. Длинные строки разбиваются по словам.

Установка: /update и перезапуск игры. Настройки сохраняются.
