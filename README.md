# X-Tools для Advance RP

Публикация готовых сборок X-Tools. Автор: Casual Alvarez.

## Установка

Скачайте X-Tools.zip из Releases и распакуйте в moonloader, сохраняя структуру папок. Перед заменой сохраните резервную копию установленного скрипта и библиотек. Архив содержит библиотеки TAB; остальные зависимости MoonLoader должны быть установлены отдельно.

## Обновления

Начиная с 3.5.28 источник обновлений подключён к этому репозиторию. Проверка доступна командой /casualupdate и в настройках системы X-Tools. Фоновая проверка включается отдельно; установка выполняется по кнопке. Скрипт проверяет SHA-256 и размеры, сохраняет CasualAT.lua.bak. Настройки и журналы обновление не заменяет. Библиотеки в lib через встроенный загрузчик не обновляются: для них используется полный архив.

После первой установки и перезагрузки обновлённого скрипта повторно войдите в аккаунт для подтверждения админ-прав сервером.

## Статус

Тестовая сборка. Офлайн-проверки не заменяют проверку в GTA SA. Известны конфликты горячих клавиш ClickWarp/телепортации и H в каптах/аптечках, замечания к статистике каптов и совместимости нативных патчей. Это не объявление стабильного релиза.

## Недостающие библиотеки (3.5.29)

Настройки → Система X-Tools → Проверить библиотеки → Скачать недостающие библиотеки. Существующие файлы сохраняются. Для не запускающегося X-Tools в полном архиве есть X-Tools-Libraries.lua: положите его в moonloader и выполните /xtlibs. Требуется установленный MoonLoader; после установки перезапустите игру. Проверяется наличие файлов, совместимость существующих версий не гарантируется.
