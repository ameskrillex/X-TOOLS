# X-Tools для Advance RP

Автор: Casual Alvarez.

## Обновление

Введите **`/update` в игре**. X-Tools скачает актуальный скрипт и необходимые ресурсы с GitHub, проверит их и перезапустится. Архивы вручную скачивать и распаковывать не нужно. Настройки, пароли и журналы сохраняются локально.

При переходе со старых версий сначала автоматически устанавливается совместимый загрузчик 3.5.295, затем полная актуальная версия. При сетевом сбое повторите `/update` — загрузчик сохраняет эту команду. Начиная с 3.5.296 обновления приходят напрямую из канала current.

После обновления полностью перезапустите GTA для выгрузки прежних нативных компонентов. Кастомное меню ESC удалено; используется стандартное меню игры.

## Первая установка

Скачайте [X-TOOL.lua](https://raw.githubusercontent.com/ameskrillex/X-TOOLS/main/X-TOOL.lua), положите в `moonloader` и запустите игру. Недостающие ресурсы и библиотеки комплекта загружаются автоматически. MoonLoader и SAMPFUNCS должны быть установлены отдельно. Не запускайте две копии X-Tools одновременно.

При ошибке начальной подготовки повторите `/xtsetup`. Существующие сторонние библиотеки не перезаписываются; их несовместимость не устраняется добавлением отсутствующих файлов.

## Хранение данных

Настройки и журналы: `moonloader/X-TOOL`. Ресурсы: `moonloader/resource/X-TOOL/<идентификатор>`. Перед заменой скрипта обновлятор сохраняет `.bak`; при переходе через загрузчик также сохраняется `.pre-bridge.bak`.
