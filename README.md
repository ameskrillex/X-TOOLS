# X-Tools для Advance RP

Публикация готовых сборок X-Tools. Автор: Casual Alvarez.

Основной файл — [X-TOOL.lua](X-TOOL.lua). Для первой установки скачайте полный [архив из Releases](https://github.com/ameskrillex/X-TOOLS/releases): скрипту также нужны ресурсы и библиотеки.

## Установка

Скачайте X-Tools.zip из Releases и распакуйте в moonloader, сохраняя структуру папок. В архиве основной скрипт называется `X-TOOL.lua`. При ручной установке замените старый основной файл `CasualAT.lua` (либо вашу переименованную копию), чтобы не запускать два экземпляра. Перед заменой сохраните резервную копию установленного скрипта и библиотек. Архив содержит библиотеки TAB; остальные зависимости MoonLoader должны быть установлены отдельно.

## Обновления

Начиная с 3.5.28 источник обновлений подключён к этому репозиторию. Проверка доступна командой /casualupdate и в настройках системы X-Tools. Фоновая проверка включается отдельно; установка выполняется по кнопке. Скрипт проверяет SHA-256 и размеры, сохраняет резервную копию с расширением `.bak`. Настройки и журналы обновление не заменяет. Библиотеки в lib через встроенный загрузчик не обновляются: для них используется полный архив.

При перезапуске скрипт проверяет текущие права через `/admins`.

Начиная с 3.5.45 основной файл и файл обновления называются `X-TOOL.lua`. С версии 3.5.44 и старше нужен однократный переход вручную: установите новый архив и удалите прежний основной файл. Настройки сохраняются.

## Статус

Тестовая сборка. Офлайн-проверки не заменяют проверку в GTA SA. Известны конфликт клавиши H в каптах/аптечках, замечания к статистике каптов и совместимости нативных патчей. Это не объявление стабильного релиза.

## Недостающие библиотеки (3.5.29)

Настройки → Система X-Tools → Проверить библиотеки → Скачать недостающие библиотеки. Существующие файлы сохраняются. Для не запускающегося X-Tools в полном архиве есть X-Tools-Libraries.lua: положите его в moonloader и выполните /xtlibs. Требуется установленный MoonLoader; после установки перезапустите игру. Проверяется наличие файлов, совместимость существующих версий не гарантируется.
